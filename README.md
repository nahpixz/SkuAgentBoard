# SkuAgentBoard
一个LLM生成与注入JavaScript实现页面自动化和批处理管理面板的Agent浏览器扩展。

在批处理任务中相比 [BrowserUse](https://github.com/browser-use/browser-use) 和 [Nanobrowser](https://github.com/nanobrowser/nanobrowser) 等方案更能节省token并避免操作的不一致性。
